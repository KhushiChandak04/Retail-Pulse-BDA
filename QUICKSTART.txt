
RETAILPULSE QUICK START

1. Open this folder in VS Code.

2. Create the single project virtual environment with Python 3.12:
   py -3.12 -m venv .venv

3. Activate it in PowerShell:
   .venv\Scripts\activate

4. Install dependencies:
   python -m pip install --upgrade pip
   pip install -r requirements.txt

   Install Git LFS separately and pull the shared processed dataset:
   git lfs install
   git lfs pull

5. Make sure Java 17+ is installed. PySpark runs in local mode; Hadoop/HDFS is
   not required for this project.

6. Run:
   python src/run_project.py

7. Open outputs/ and verify the generated CSV files.

   This includes validation_summary.csv, which compares independent Pandas
   metrics with the Spark SQL results.

8. Open Power BI Desktop.

9. Import:
   outputs/sales_transactions.csv

10. Follow:
    powerbi/dashboard_guide.md

11. Run the Streamlit experience:
   streamlit run streamlit_app.py

12. Optional: put the published Power BI embed URL in `.env` as
   `POWERBI_EMBED_URL` to display the live Power BI report inside the app.
